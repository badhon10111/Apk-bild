# AdNetwork Android UI Demo

A native Android Java starter project inspired by the supplied AdNetwork screenshots.

## Included
- Home/feed screen with stats, campaign banner, page overview, progress, post card, Like and Auto Play demo controls
- Side navigation drawer with Feed, My Links, Campaign, Explore, Profile, Stats and Log Out
- GitHub Actions workflow to build a debug APK

## Build with GitHub
1. Create a GitHub repository.
2. Upload the contents of this ZIP to the repository root.
3. Open **Actions** and run **Build Android APK**, or push a change to `main`.
4. Open the successful workflow run and download the `AdNetwork-debug-apk` artifact.
5. Extract the artifact ZIP to get `app-debug.apk`.

## Important
This is a UI/demo starter. Stats and feed content are sample data; Like and Auto Play are local demo interactions only. No Adsterra login, ad viewing, or external service integration is implemented. Connect only to APIs you own or are authorized to use.
